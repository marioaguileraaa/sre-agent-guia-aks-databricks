# Microsoft Azure architecture icons

These eleven unmodified SVGs are the small subset used by the Case 04
architecture diagrams. They come from **Azure Public Service Icons V24**,
downloaded on **2026-10-13** from Microsoft's official distribution:

- Usage guidelines and terms: <https://learn.microsoft.com/en-us/azure/architecture/icons/>
- Archive: <https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip>
- Original archive entries, sizes and SHA-256 values: [`manifest.json`](manifest.json)

Microsoft's usage guidelines require the product name near the icon. Do not
crop, flip, rotate, distort or change its shape, and do not use Microsoft
product icons to represent this report or another product/service. These
assets are **not** relicensed under the checklist's MIT license.

The report embeds the original SVG bytes as static data URIs: no CDN, external
script, font or SVG resource fetch. The selected SVGs were checked for scripts,
event handlers, active elements and external references. Proportional scaling
uses the original viewBox; Microsoft-authored paths and paint are unchanged.
An icon indicates a named product, not deployment, ownership, health or
verified traffic. The observed and undeployed reference diagrams stay separate.
